# Bundled Resource Provenance

The Dryless eye assets and alert sounds were copied from the Windows handoff branch `codex/macos-handoff-rc8` at `788927b`. Their original repository paths are `icon.png`, `assets/icons/`, and `sounds/`. The open-eye line source is copied unchanged from `icon.png`; macOS converts its monochrome ink into a transparent template at runtime.

The GitHub mark is the official Primer Octicon `mark-github-16.svg`, downloaded from `github/primer` at `https://raw.githubusercontent.com/primer/octicons/main/icons/mark-github-16.svg`. It is covered by the bundled `Licenses/github-octicons-LICENSE.md`.
