# Eye states

The original open-eye artwork is preserved unchanged. The user requested a matching closed state on 2026-09-13.
eye-closed-source.png was created by imagegen as an edit of the existing icon.png: same left teardrop, upper crease and tapered right eyelashes, fully closed eyelid with no iris. A second edit removed the generated checkerboard background to produce a monochrome source.
Qt renders its luminance as alpha, then applies the same sage tint as the existing open eye. This avoids a background square and keeps antialiased edges. No original logo file was replaced.
Running camera = open. Off/starting/stopping/error = closed. Pause alerts does not close an active eye. The same family drives branding, navigation, page/metric eyes, window/taskbar and tray. Tips' explicit closed-eye rest illustration expresses its content.
