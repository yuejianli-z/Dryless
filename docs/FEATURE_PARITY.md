# 双平台功能合同 / Feature parity

以下是 Windows 与 macOS 共同验收标准，不得因平台而删改。

| 模块 | 必须保持一致的行为 |
| --- | --- |
| 检测 | 同一 MediaPipe 模型及 blink_detector.py 算法；摄像头预览可隐藏但检测继续 |
| 提醒 | 默认 8 秒首次提醒，之后每 5 秒进入下一档；仅三档，第三档之后按间隔重复，眨眼重置 |
| 音色 | Polite(65)、Sharp(79)、Original、Blip；对应 release-assets.json 同样的音频文件 |
| 试听 | 一键顺序听三档，间隔 0.8 秒；切音色、换设置标签或离开设置页立即停止 |
| 暂停/静音 | 暂停停止提醒并重置连续在场计时；静音仅关闭声音，屏幕提示保留 |
| 微休息 | 连续有效在场 25 分钟触发一次固定声音；无需用户选择，设置不外显 |
| 微休息持续 | 提示最长 30 秒，离开摄像头 20 秒可提前结束；结束后重新计 25 分钟 |
| 在场容错 | 丢脸不超过 5 秒保留此前累计但不计入丢失时长；超过 5 秒或采集时间跳变清零 |
| 提醒协调 | 微休息期间停止眨眼声音与横条；结束后重新等待首次提醒时间，不补发旧提醒 |
| 首页 | 摄像头、识别状态、距上次眨眼、本次眨眼/提醒/运行时长、分钟节律格；不用折线图或详情弹窗 |
| 统计 | 近30天、整年、全部、自选日期；日/周/月/自动粒度的时间气泡图；气泡面积表示记录时长 |
| 统计语义 | 频率=总眨眼/记录分钟，加权平均；无记录与真实零值区分；参考带与实际平均线区分 |
| 导出 | CSV 与所选范围和聚合口径一致；保留中文/英文与空数据行为 |
| 设置 | 提醒时长、音色、静音、摄像头分辨率、语言、检测参数；保存并重启仍有效 |
| 双语 | 中文/英文切换不移动控件；Language 按钮文字恒定，等宽控件文字居中 |
| 视觉 | 当前详细人眼 Logo；内部眼睛是绿色同形图；字号/间距统一；无垂直页面滚动 |
| 本地数据 | 只存设置与数值历史；不上传/落盘摄像头图片或视频；升级保留已有数据 |

允许平台差异：原生窗口交通灯/Windows 窗口键、菜单栏/托盘、权限提示、
系统字体回退、系统文件选择器、安装包形式。三页导航、内容层级、图表语义与功能不变。

统计中的旧记录分钟不等于有效人脸检测时长，不能在 Mac 上偷换分母。
15–20 次/分是一般参考带，不是个体诊断；更高频率不能标成健康评分。
