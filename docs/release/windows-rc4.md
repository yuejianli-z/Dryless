# Windows rc.4 · 独立 Tips 与公共开关

全局摄像头/声音开关并排置于顶部，大小一致，中英文/三页位置不变。
监测右侧：上方当前状态与四项指标，暂停提醒靠近当前状态；下方独立浅绿Tips卡片。
Tips有对应图标、四字标题、长度相近的短文案与三个静默位置点；无下一条按钮。
每20秒自动切换，悬停、键盘焦点、活动提醒、隐藏页面及最小化时暂停。
按最终反馈只留自然轻眨、远眺休息、短暂闭眼；来源和完整文案见 FEATURE_PARITY.md 第7节。
保留摄像头优先布局、底部分钟节律、统计气泡图、现有声音和20分钟微休息规则。

## 验证
- 185项实际Qt中英文三页布局检查通过，截图使用合成画面。
- 38项模拟摄像头生命周期检查通过，包含移动后的顶部声音控件。
- 131项轮播/双语布局检查通过；实际等待20秒确认自动轮换，其余边界加速测试。
- 包内自检62项通过；构建来源与文件哈希见windows-rc4-validation.json。
- 本轮没有复测物理摄像头，rc.3真机证据保持独立。未验证Mac与连续20分钟真人检测。
