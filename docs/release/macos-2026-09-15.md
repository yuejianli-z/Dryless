# macOS 0.2.0 rebuild - 2026-09-15

This update replaces the macOS source and the complete runnable bundle at
`macos/release/Dryless.app`. Windows binaries, Windows source, and README
screenshots are unchanged.

## Changes

- Camera resolution selects an exact device active format. Unsupported sizes
  produce a localized error instead of silently selecting a nearby format.
- Every incoming pixel buffer is checked before Vision processing. A resolution
  mismatch stops capture and reports the requested and received dimensions.
- The default capture format is 640 x 480. Live device checks confirmed
  640 x 480, 1280 x 720, and 1920 x 1080 through consecutive input frames.
- Relative eye calibration, small eye-landmark overlays, clipped camera preview,
  and 18-point menu-bar artwork include the locally accepted fixes.
- Packaged icons and audio resolve inside the app resource bundle.

## Build and validation

Run `bash macos/script/package_release.sh 0.2.0` from the repository root.
The result is a release-optimized Apple Silicon app targeting macOS 14 or later.
The app is ad-hoc signed, not Developer ID signed or notarized.

`swift run DrylessCoreChecks` passed. The release bundle is checked with
`codesign --verify --deep --strict` and `plutil -lint`.
Camera diagnostics log only dimensions and frame counters, never images.

## Windows integration

Preserve executable mode on `Contents/MacOS/DrylessMac` and preserve the entire
`.app` directory, including `_CodeSignature` and the nested resource bundle.
Do not rebuild the macOS executable on Windows or replace individual resources
after signing. Use this commit's source together with this commit's app bundle.
The normal app uses live camera input and local user data; README demo mode
requires explicit command-line arguments and no sample portrait is bundled.

The existing `v0.2.0` tag is not moved by this rebuild. Download this updated
bundle from the updated branch rather than the old tag's source snapshot.
