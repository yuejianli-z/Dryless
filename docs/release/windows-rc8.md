# Windows rc.8 · 悬停、顶部控件和频率口径

- 中文标语为“多眨眼，少干涩”；英文仍为“Blink more, dry less”。
- Windows桌面图标沿用原眼睛轮廓和透明背景，由应用既有图标渲染器导出浅绿色#78977E，包含16至256像素七种尺寸；原始图标资源保留。快捷方式统一命名Dryless。
- 原版音色的显示名改为Ding，资源键original及原有音频文件不变。点击任意音色播放第一档一次，再次点击也可重听。
  “试听三档”仍播放三档；点三档按钮会替换当前单声试听，快速切换取消旧声音，微休息优先级不变。不添加操作说明文案。
- 摄像头与声音使用对应的小图标按钮，关闭时同一图标叠加柔和红色斜线；与 Language 同为28像素高。
  双语不改变按钮大小；可访问名称保留开关状态，托盘菜单保留文字操作项。
- 清除当前桌面代码中的17处非空悬停提示入口（16处setToolTip、1处显式showText），移除黑色QToolTip样式。
  QApplication拦截自动ToolTip事件及显式ToolTip窗口；原生托盘提示为空。主动打开的菜单和图表说明仍可用。
- 气泡日期、频率、时长、计数、天数及部分周期信息显示在图内固定两行区域，鼠标与键盘选择均不遮挡图表或移动页面。
- 频率口径：有效识别期间的眨眼次数 × 60 / 同期有效识别秒数。30秒有效识别、10次眨眼，圆环、单分钟色块和均值均为20次/分钟。
  首次采样、重获识别且无连续有效时间、重复时间戳的事件不再单独进入分子。
  有效识别不足30秒仍为缺测；旧窗口边界和缺测规则保留，不以30次为上限。

## 验证

- `python -B -m unittest discover -s tests -q`：32项。
- `python -B tools/qa_live_metrics.py`：24项，包含30秒/10次示例从统计到页面的验证。
- `python -B tools/qa_no_hover_popups.py`：87项，含暂停长悬停、全页扫描、中英状态刷新、显式tooltip回归、菜单与图内明细。
- `python -B tools/qa_ui.py`：186项；1100×700、1240×780、中英、三页与设置各标签，无竖向滚动或布局越界。
- `python -B tools/qa_ui_consistency.py`：227项；原状态图标、双语按钮、托盘一致。
- `python -B tools/qa_camera_windows.py`：38项合成摄像头生命周期检查。
- `python -B tools/qa_sound_selection.py`：50项选择即试听、重复点击、单声切三档、取消和双语检查。
- `python -B tools/qa_reminders_windows.py`：66项提醒、原声音资源与优先级检查。
- `python -B build.py`、包内`--self-test`通过；源提交与哈希见windows-rc8-validation.json。
- 处理了测试脚本在未运行app.exec时的原生控件析构顺序，断言后显式刷新DeferredDelete，测试进程正常退出。

## 范围与限制

按用户最终要求保留原有眨眼检测算法，不引入新的检测阈值、抗抖动或频率封顶。
修正统计事件与有效时间的一致性，不声称已解决模型原始计数偏高。既有记录不删除、不重写。
历史统计仍为旧的已保存分钟口径；旧文件没有有效眼部识别秒数，不能追算成相同的有效时长频率。
未重测真人摄像头精度、20分钟真实等待或Mac真机，不代表F2全部完成。
缺失日期的短虚线连接仅为讨论建议，当前气泡图仍保持缺失处断开，没有补造气泡。
