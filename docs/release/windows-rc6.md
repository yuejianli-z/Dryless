# Windows rc.6 · 最近60秒与实时进度

## 行为变化
- 主指标替换为距上次眨眼的计时进度、最近60秒频率圆环、20分钟微休息进度。保留摄像头左栏、Tips卡片与下方分钟节律。
- 频率从“累计/当前分钟混合并截断到30”改为真实滑动窗口；最近60秒有效识别不足30秒显示采集中，丢脸/摄像头关闭时不冒充当前数据，有效零次仍显示0。
- live_metrics.py共用眨眼事件和有效识别时间计算滑动窗口与固定完整分钟。补正分钟边界事件归属，首个眨眼不再因初始化桶丢失；旧历史格式/分母不迁移。
- 圆环与色块使用同一红、黄、灰调鼠尾草绿映射。圆环标出频率刻度，超过40时扩展刻度，不代表健康分数。
- 未眨眼进度标记三档真实触发点，超过末档不循环；微休息或暂停时停止提醒进度。微休息用连续在场时间，不拿运行时长代替。
- 节律与颜色图例取消悬停弹窗。点击/方向键选择分钟后，精确值直接显示在图内。历史气泡的数据明细仍保留。
