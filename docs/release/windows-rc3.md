# Windows rc.3 · 摄像头控制与首页

本次改动针对 Windows，不把 macOS 视为完整答案，不替换原生 Mac UI。

- 公共标题栏：开启/取消开启/关闭/重试摄像头；固定尺寸，中英文位置一致。
- 监测：左侧画面；右侧状态、2×2 指标（距上次眨眼、本次眨眼、本次提醒、本次时长）、护眼 tip、等宽操作按钮；底部保留分钟节律。
- 侧栏：恢复 Blink more, dry less / 多眨一眼，少一分干涩。
- 托盘：打开、摄像头、暂停/恢复提醒、声音、退出；关闭窗口时保留后台入口；停止为闭眼，暂停为标记。
- 设置：分辨率说明改为下次开启镜头生效；恢复预览偏好。统计气泡图、品牌资产及检测算法保持原样。

首次安装/未保存启停偏好的升级用户，镜头保持关闭。用户点击开启才采集；后续保存明确选择。
关闭立即清画面/停止接受旧数据与提示，释放完毕才能再次开启。开启新会话清本次数值，历史保留。

## 内容依据
护眼内容依据 [Mayo Clinic Eyestrain](https://www.mayoclinic.org/diseases-conditions/eyestrain/diagnosis-treatment/drc-20372403)：
自然眨眼、20分钟/20英尺/20秒、减少反光和直吹。约6米对应20英尺。不表示相机能够证明用户看向远处。
