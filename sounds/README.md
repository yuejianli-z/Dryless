# Current sounds

Dryless 0.2.0 ships four selectable three-stage blink-reminder themes and one
fixed microbreak cue. Exact asset hashes are recorded in `release-assets.json`.

- `polite/`: Polite stages 1-3
- `sharp/`: Sharp stages 1-3
- `original/`: Ding stages 1-3 (the internal key remains `original`)
- `blip/`: Blip stages 1-3
- `microbreak/started.wav`: fixed 20-minute microbreak cue

Only these files are bundled. Licensing and provenance are documented in
`BUILTIN-SOUNDS.md` and the accompanying license files.
